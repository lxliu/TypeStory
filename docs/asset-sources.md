# 素材与实现说明

地鼠 SVG、页面样式、键盘和手指示意均为本工程自制，无外部素材依赖。音效与原创木琴风格循环旋律由 Web Audio 正弦波合成，字体采用系统字体。没有网络请求、分析脚本或 CDN。

键盘按美式 ANSI 字符映射；Windows 预设切换功能键名称。Fn 与部分系统功能键未必向网页发送事件。标准指法仅作教学提示，软件不能判断实体手指。

题库在 js/lessons.js 中维护。C++ 阶段的简短片段用于键盘练习，并非完整可编译程序。模板仅采用预定义 a/b/c 与 1/2/3。

首页键盘、短句插图与小锤 SVG 均在工程内原创绘制。游戏地鼠使用原地鼠图形的局部视图 mole-bust.svg；没有新增外部音频素材。命中“啵”和上扬音由 Web Audio 合成，效果音和背景音乐经独立 GainNode 混音。

`mole-bust.svg` 与 `mole-hit.svg` 为本工程原创完整地鼠与受击表情，不含背景或洞口；洞口由页面单独绘制。
