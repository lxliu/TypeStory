# 素材与实现说明

本项目运行素材全部保存在工程内，不使用 CDN、分析脚本或网络音频。字体采用系统字体。

- `mole-bust.svg`：原创完整地鼠身体，不含背景及洞口。
- `mole-hit.svg`：对应的闭眼受击表情。
- `hammer.svg`：原创卡通小锤。
- `trophy.svg`、`settings.svg`：统一风格的本地奖杯和设置图标。
- 普通模式洞口使用本地 SVG；帮助模式洞口、星星、“+1”、按键与交互状态由HTML/CSS呈现。身体钻洞由单独遮挡层实现。
- `mole.svg`、`keyboard-card.svg`、`phrase-card.svg` 是旧版原创素材，当前主界面不引用。

背景音乐为原创木琴风格循环旋律，使用 Web Audio 正弦波合成。命中“啵”和上扬音通过独立效果通道播放，降低音乐音量不影响命中声。

键盘按美式 ANSI 字符映射；Windows预设切换功能键名称。标准指法仅作教学提示，软件不能判断实体手指。符号与字符范围维护在 `js/lessons.js`，不随机拼接代码。

`hole.svg` 与 `hole-front.svg`：项目内原创扁平卡通土洞，使用深棕洞内、浅棕土边和轻微阴影；完整图与前沿图共用同一轮廓，保证钻洞时洞口外观不变。无草叶、渐变或外部资源。
