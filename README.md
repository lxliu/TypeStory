# TypeStory · 地鼠键盘花园

用 Chrome 打开本目录的 **index.html** 即可。所有运行资源均在本地，无需安装、联网或启动服务。请保持整个目录一起移动。

练习前切换 macOS 输入源到 **ABC / 英文**。点击开始后启用音效；声音、键盘布局与三档大字号在右上角设置中调整。

## 三种玩法

- 键盘探索：只用实体键盘，认识字符、位置和手指。
- 地鼠出没：选择阶段与帮助模式，60 秒内正确输入加一分，错误不扣分。无提示模式可以主动求助。
- 短句小径：依次输入，不限时；错误停在当前字符。完成后自动保存，允许自由选关。

推荐每天 10–15 分钟：自由热身 → 帮助模式 → 普通模式 → 短句挑战。先准确，再提高速度；适时休息并看远处。

## 进度与备份

进度和设置保存在 Chrome 的 localStorage，不写入工程文件。清除浏览器数据、改变 HTML 路径、使用其他浏览器配置可能无法恢复记录。在设置中导出 JSON 备份，导入会替换当前设置与进度。存储不可用时会显示提示，练习仍然可用。

窗口失焦或切换标签页会暂停，点击继续恢复。本局分数不保存；短句中途退出时下次重做当前题目。准确率只统计字符输入，Shift 等修饰键、自动重复不计数；求助单独统计。

## 目录与检查

`css/` 样式；`js/` 逻辑、题库、布局；`assets/images/` 图形；`assets/audio/` 预留录制音效；`docs/` 设计说明；`tests/` 行为测试。音效当前全部由 Web Audio 本地生成。

运行测试：`node tests/core.test.js`。无第三方运行依赖。浏览器快捷键和系统组合键由操作系统保留；软件不尝试拦截 Command 等快捷操作。
