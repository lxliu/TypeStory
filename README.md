# TypeStory · 地鼠键盘花园

给 8 岁键盘初学者的离线盲打练习软件。通过键盘探索、打地鼠和短句挑战，逐步熟悉英文字母、数字及 C++ 常用符号，减少学习编程时看键盘、找按键的次数。

使用原生 HTML、CSS、JavaScript、SVG 和 Web Audio 实现，无后端、第三方运行依赖、CDN 或在线资源。下载整个工程后即可练习。

## 快速开始

1. 下载并解压整个项目，或克隆仓库。
2. 用 **Chrome** 打开项目中的 [index.html](index.html)，无需安装依赖或启动服务器。
3. 切换到 **ABC／英文输入源**，浏览器缩放设为 **100%**，内容区至少 **1280×700**。
4. 选择一种玩法，点击开始。首次进入键盘探索，也可以直接按实体键开始。

默认使用美式 MacBook 键盘布局；设置中可切换美式 Windows 功能键名称，并调整三档字符大小、音效音量和背景音乐。练习只接受实体键盘输入，不通过点击屏幕键帽答题。

请保持整个目录一起移动。资源均使用相对路径，断网也能运行；不需要浏览器扩展。

## 三种玩法

| 玩法 | 练习内容 | 规则与提示 |
| --- | --- | --- |
| 键盘探索 | 自由认识键位、字符和指法 | 实体按键触发高亮与按键声，刚输入的字符对应键内显示手指名称。 |
| 地鼠出没 | 基准位、小写、大写、数字与基础符号、Shift 符号、综合练习 | 每局 60 秒，一次一只地鼠；答对加一分，答错不扣分，未答对时地鼠一直等待。 |
| 短句小径 | 键位组合、英文单词、大写与符号、C++ 简短片段 | 不限时，严格按顺序输入；答错不推进，无需退格，完成后保存题目进度。 |

### 帮助与输入反馈

- 地鼠帮助模式以完整键盘为洞穴；普通模式使用随机的 3×3 洞穴，可主动求助。帮助开关即时切换，保留当前目标、时间和成绩。
- 短句帮助模式显示键盘与当前目标键；普通模式隐藏键盘，可主动求助。内容来自本地人工设计题库，优先抽取未完成题目，全部完成后可继续巩固。
- 目标键采用暖黄色背景和粗轮廓，手指名称直接显示在键内。需要 Shift 时，两个 Shift 同时提示“按住”，任意一侧均可；判定按实际输入字符，也允许 Caps Lock。
- 空格统一显示为 **“空格”**；短句中的空格使用带边框的占位块，实际需输入一个普通空格。
- 按住键产生的自动重复不计分；单独按修饰键不计错误。准确率为正确次数 ÷（正确次数＋错误次数），求助次数单独统计。

### 地鼠趣味反馈与控制

两种地鼠模式共用约 **650 毫秒**的命中过程：挥锤 → 压扁与受击表情 → 弹起、星星和“+1” → 钻回洞里 → 下一只出现。锤子接触时播放“啵”，弹起时播放上扬音，背景音乐短暂降低音量。

正确输入即时加分，动画期间额外输入不计分、不计错，倒计时继续。错误时地鼠温和摇头并继续等待。系统开启“减少动态效果”时，保留受击表情、星星、“+1”和声音反馈，减少大幅运动。

地鼠游戏运行时播放本地合成的原创木琴风格背景音乐，可单独关闭或调整音量；总静音同时控制音效与音乐。

三种玩法均支持暂停与结束确认。失焦、切换标签页、打开设置或确认框会暂停；暂停冻结命中动画及尚未触发的声音。结算可选择“再玩一次”“留在这里”或“返回首页”，关闭结算弹窗也会留在当前模式。

## 练习进度与备份

设置与短句进度保存在浏览器 **localStorage** 中，不自动写入工程目录，也不上传到服务器。

- 短句常驻显示“本阶段已完成 X/Y”；重复完成同一题不增加完成数，并记录各题最好准确率和最短完成耗时。
- 完成一题后自动保存；中途退出或提前结束不记为完成，下次从该题开头重做。
- 可重置当前阶段，或在设置的“练习进度”中重置全部短句记录；重置保留键盘布局、字号、音量、所选阶段和帮助偏好。
- 设置支持 JSON 导出与导入。**导入会替换当前设置与进度**，重置或导入前建议先导出备份。旧备份缺少音乐设置时会补充默认值。
- 浏览器存储不可用时仍能练习，页面会提示无法自动保存。

清除浏览器数据、移动项目路径、更换浏览器或用户配置可能导致原进度无法读取。尤其在 `file://` 下，不应把浏览器存储当作唯一备份。

第一版没有排行榜，本局地鼠成绩仅用于当前结算，不保存历史排名。

## 建议练习顺序

每天约 **10–15 分钟**：键盘探索热身 → 帮助模式找键 → 普通模式挑战 → 短句连续输入。

先练准确，再提高速度。双手轻放在 F 和 J，尽量看屏幕提示，适时休息并看远处。C++ 短句仅用于字符输入练习，不一定是完整可编译程序。

## 工程结构与开发

```text
TypeStory/
├── index.html             # 页面入口，可通过 file:// 直接打开
├── css/main.css           # 固定窗口布局、键盘与游戏样式
├── js/
│   ├── app.js             # 界面、输入与练习流程
│   ├── core.js            # 计分、计时、进度与数据校验
│   ├── keyboard.js        # 键盘布局、字符映射与指法提示
│   ├── lessons.js         # 本地阶段与短句题库
│   └── audio.js           # 音效和背景音乐合成
├── assets/images/         # 本地原创 SVG 图形
├── docs/asset-sources.md   # 素材与实现说明
├── tests/                 # Node.js 行为测试
└── README.md
```

JavaScript 使用普通脚本加载，题库直接定义在 JS 中，不依赖本地 `fetch()` 或 ES 模块。声音由 Web Audio 合成，无需下载音频文件。素材说明见 [docs/asset-sources.md](docs/asset-sources.md)。

开发检查需要可用的 Node.js；直接运行软件不需要 Node.js。无需 `npm install`：

```sh
node tests/core.test.js
node tests/audio.test.js
node --check js/app.js
node --check js/core.js
node --check js/audio.js
```

行为测试覆盖字符映射、双 Shift 提示、计分与计时、暂停和提前结束、短句进度与重置、旧备份兼容，以及命中动画输入锁和音效触发时刻。音频测试使用模拟对象检查音乐生命周期、音量通道与静音行为，不代替实际听感检查。

## 验证状态与已知限制

当前行为测试、音频状态测试和 JavaScript 语法检查已通过。**最新地鼠动画的实际浏览器截图与音效听感尚未完成验收**，不能把自动检查等同于视觉与趣味性验收。

浏览器验收应通过 Chrome 本地文件方式、断网运行，在 **1280×700、1280×800、1440×900** 内容区检查三档字号，并覆盖两种地鼠模式、动画各阶段、暂停恢复、帮助切换及结束边界。

- 界面固定窗口且不滚动；内容区过小时提示放大窗口。
- 指法是教学建议，网页无法判断孩子实际使用了哪根手指。
- Fn 等部分功能键可能不向网页发送事件；Command、Control、Option 等系统或浏览器组合键保留系统行为。
- 当前不提供中文／拼音输入练习，也不要求 Tab 或换行完成短句。
