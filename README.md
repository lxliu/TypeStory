# TypeStory · 地鼠键盘花园

用 Chrome 打开本目录的 **index.html** 即可。所有运行资源均在本地，无需安装、联网或启动服务。请保持整个目录一起移动。

练习前切换 macOS 输入源到 **ABC / 英文**。点击开始后启用音效；声音、键盘布局与三档大字号在右上角设置中调整。

## 三种玩法

- 键盘探索：只用实体键盘，认识字符、位置和手指。
- 地鼠出没：选择阶段与帮助模式，60 秒内正确输入加一分，错误不扣分。无提示模式可以主动求助。
- 短句小径：依次输入，不限时；错误停在当前字符。完成后自动保存，允许自由选关。

推荐每天 10–15 分钟：自由热身 → 帮助模式 → 普通模式 → 短句挑战。先准确，再提高速度；适时休息并看远处。

## 进度与备份

进度和设置保存在 Chrome 的 localStorage，不写入工程文件。清除浏览器数据、改变 HTML 路径、使用其他浏览器配置可能无法恢复记录。在设置中导出 JSON 备份，导入会替换当前设置与进度。存储不可用时会显示提示，练习仍然可用。

窗口失焦或切换标签页会暂停，点击继续恢复。本局分数不保存；短句中途退出时下次重做当前题目。准确率只统计字符输入，Shift 等修饰键、自动重复不计数；求助单独统计。

## 目录与检查

`css/` 样式；`js/` 逻辑、题库、布局；`assets/images/` 图形；`assets/audio/` 预留录制音效；`docs/` 设计说明；`tests/` 行为测试。音效当前全部由 Web Audio 本地生成。

运行测试：`node tests/core.test.js`。无第三方运行依赖。浏览器快捷键和系统组合键由操作系统保留；软件不尝试拦截 Command 等快捷操作。

## 固定窗口界面与练习控制

浏览器内容区需至少 **1280×700**（100% 缩放）；界面不滚动，更小窗口会提示放大。三档字符大小保留，指法名称直接显示在目标键内，设置分为显示与声音、练习进度两个页签。

帮助可随时切换，不重置题目、时间或成绩。普通模式求助只显示紧凑提示卡。空格统一以中文“空格”显示，请按键盘最下面的长空格键。

三种练习均可点击“结束”并确认。取消恢复原状态；切离窗口后保持暂停。短句提前结束不增加完成数，下次重做同一题。模式 3 显示本阶段已完成题数；可确认重置当前阶段，也可在设置中重置全部短句记录（完成记录、最好成绩、待练题及顺序记录），保留设置和阶段偏好。重置前建议导出备份。


## 目标键与背景音乐

练习页面采用单行工具栏、单行状态区和主练习区。目标键使用暖黄色背景与粗轮廓，并直接标注左食指、右中指等；无需查看独立图例。需要 Shift 时两侧同时显示“按住”，任意一侧均可。自由练习的指法提示保留至下一次字符输入。

地鼠游戏默认播放低音量的原创木琴风格背景音乐，完全本地合成。在设置的“显示与声音”中可单独关闭或调整音量。暂停、失焦、设置或结束确认期间音乐暂停，继续时恢复；返回首页或结算后停止。旧进度备份自动补充音乐默认设置。

音频状态测试：`node tests/audio.test.js`。


## 地鼠命中与结算

帮助和普通模式共用约 450 毫秒的命中过程：小锤轻敲、地鼠压缩弹起、星星与 +1、地鼠缩回洞穴。旧地鼠完成退场后才生成下一只；动画期间额外敲键不计分也不计错，倒计时继续。暂停会冻结动作，退出和结束会清除动作。错误时地鼠摇头，继续等待。

命中音效独立于背景音乐播放，命中时音乐会短暂降低音量。系统“减少动态效果”设置下使用静态星星、+1 与音效反馈。

结算可选择“再玩一次”“留在这里”或“返回首页”；关闭弹窗也会留在当前模式。阶段、帮助开关及本局统计保留。

首次进入自由练习时，直接按实体键也会开始并启用按键音效。Shift、Caps Lock、退格、回车、Tab、方向键和字符键均有声音；暂停、结束和长按重复时不发声。系统快捷键保留系统行为。
